# 小学数学讲解视频生成工作流

## 概述

将一道数学题 → 生成完整的讲解视频（含板书动画 + 语音旁白）+ 结构化知识库。

## 模板文件清单

| 文件 | 用途 |
|------|------|
| `关联知识表.csv` | 81条知识点索引：学段/系列/类型/知识点/经典样题/考点/策略方法/讲解要点/易错点/总结归纳 |
| `1_读题话术.csv` | 读题环节话术模板（20条） |
| `2_分析话术.csv` | 分析环节话术模板（16条） |
| `3_解题步骤.csv` | 解题步骤按步骤切片（空模板，需填入） |
| `4_语言润色.csv` | 模块间/步骤间过渡衔接话术（22条） |
| `5_总结切片.csv` | 总结环节话术：方法概括/易错强调/规律总结/结束语（20条） |
| `[知识库]小数题目类型.docx` | 16个题型分类，每类含：题目示例 + 语音原文 + 文本提示词(ROSES/CRISPE框架) + 板书提示词 |

## 工作流（4个阶段）

### Phase 1: 题目解析 + 知识检索

**输入**: 一道数学题 + 题型标识

**动作**:
1. 解析题目，识别学段、系列、类型（口算/竖式/脱式/简便运算/小数/分数/时间/单位换算...）
2. 查询 `关联知识表.csv`，匹配编号 → 获取该知识点的：策略方法、讲解要点、易错点、总结归纳
3. 查询 docx 中对应的题型分类 → 获取对应的提示词模板（ROSES/CRISPE框架）

**skill-creator 职责**: 将上述数据源封装为一个 skill，定义触发条件、数据查询逻辑、输出格式。skill 的 `references/` 存放 CSV 和 docx 摘要，`scripts/` 存放题目解析脚本。

**tutor-skills 职责**: 如果该知识点还没有 StudyVault，用 `/tutor-setup` 从关联知识表生成结构化笔记；已有 StudyVault 则用 `/tutor` 进行诊断/练习。

---

### Phase 2: 脚本生成（5段式话术）

**输入**: Phase 1 输出的知识点数据 + 题目内容

**动作**: 按固定5段结构生成完整讲解脚本

| 段落 | 来源模板 | 内容 |
|------|---------|------|
| 1. 读题 | CSV#1 读题话术 | 介绍题目类型、读出题目、指出关键信息 |
| 2. 分析 | CSV#2 分析话术 | 关联知识点、分析解题思路、指出注意事项 |
| 3. 解题 | CSV#3 + 关联知识表的讲解要点 | 按步骤逐步解题（步骤间用 CSV#4 衔接） |
| 4. 过渡 | CSV#4 过渡话术 | 步骤间衔接、模块间衔接 |
| 5. 总结 | CSV#5 总结话术 | 方法概括、易错强调、规律总结、结束语 |

**脚本格式要求**:
- 每段标注预计时长（秒）
- 解题步骤每步标注板书内容（写什么、画什么）
- 过渡话术标注类型（步骤开始/步骤强调/步骤衔接/步骤小结）

---

### Phase 3: 板书分镜设计

**输入**: Phase 2 的脚本 + 关联知识表数据

**rsa-whiteboard-teacher 职责**: 将脚本转化为白板动画分镜表

**动作**:
1. 按脚本段落拆分为独立场景（每场景30-60秒）
2. 每场景生成：场景编号 + 时长 + 视觉描述 + AI手绘图片提示词 + 旁白逐字稿
3. 板书特殊处理：
   - 公式/算式：用自定义手写字体（opentype.js），PNG透明底 + stroke2vec笔顺分段播放
   - 图形/示意图：黑白手绘风格，image_to_svg.py 转 SVG
   - 重点标注：红色/箭头强调
4. 审核优化：时长检查 + 流畅度检查 + 视觉-旁白对齐检查

**输出**: 分镜表（markdown/xlsx格式）

---

### Phase 4: 资产生成

**输入**: Phase 3 分镜表

**动作**:
1. 图片资产：AI生成黑白手绘图 → image_to_svg.py 转 SVG（可选）
2. 板书动画：Canvas 逐笔书写动画（board-writer 系统）
3. 语音资产：旁白逐字稿 → TTS 生成语音
4. 合成：分镜表 + 图片/SVG + 板书动画 + 语音 → 视频合成

**tutor-skills 职责**: 视频生成后，提取知识点生成练习题，加入 StudyVault 供学生巩固。

---

## 各 skill 在工作流中的角色

| skill | 角色 | 产出 |
|-------|------|------|
| **skill-creator** | 工作流本身的封装器 | 将整个流程打包为一个可复用的 skill（math-video-generator） |
| **tutor-skills** | 知识库管理 + 练习生成 | StudyVault 知识笔记 + 诊断测试 + 练习题 |
| **rsa-whiteboard-teacher** | 板书分镜设计器 | 分镜表 + 手绘提示词 + 旁白脚本 |

## skill-creator 打包建议

将本工作流封装为 `math-video-generator` skill：

```
math-video-generator/
├── SKILL.md                    # 工作流指令（触发条件 + 4阶段步骤）
├── references/
│   ├── knowledge-index.md      # 关联知识表摘要（81条知识点索引）
│   ├── script-templates.md     # 5段话术模板汇总
│   └── prompt-frameworks.md    # ROSES/CRISPE 提示词框架说明
├── scripts/
│   ├── parse_question.py       # 题目解析 + 知识点匹配
│   └── generate_storyboard.py  # 脚本 → 分镜表转换
└── assets/
    ├── storyboard-template.xlsx # 分镜表模板
    └── script-template.md       # 脚本模板
```
