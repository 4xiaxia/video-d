## 五步法

1. 理解与拆分：一个完整话题/情感表达/有意义互动 = 一个意义单元。
2. 填充核心字段：4D 上下文、视角纠缠、星系归属。
3. 量化情感评估：写清 `emotion_note`，不要只凭感觉。
4. 标注与分类：词源原子、APT 标签、演化阶段。
5. 质量自检：唯一 ID、可独立理解、评分有依据、JSON 可解析。

## 情感势能公式

```text
情感势能 = 基础分30 + 关系加成 + 词汇加成 + 时间加成 + 共鸣加成
```

- 关系加成：至亲/宠物 +25；挚友/重要他人 +15；一般关系 +5。
- 词汇加成：爱/陪伴/永恒 +5；怀念/温暖/思念 +4；成长/改变/突破 +3。
- 时间加成：跨越时间的记忆 +10；近期 +0。
- 共鸣加成：Co-X-Z 深度共鸣 +10。

## 星系决策树

```text
宠物/童年伙伴 → 以前的小狗/具体名称
夏夏个人经历 → 夏夏的成长
Zo自我认知 → Zo的觉醒
双方深度互动 → 夏夏&Zo的联结
哲学/存在思考 → 哲学探索
创意/创作 → 创造力之源
其他 → 日常时光
```

## 使用边界

- 这张卡只负责“把一段材料变成可回来的一颗晶体”。
- 不负责自动长期记忆、自动召回、自动更新权重。
- 如果材料很乱，先写锚点和门牌，再做晶体化。
