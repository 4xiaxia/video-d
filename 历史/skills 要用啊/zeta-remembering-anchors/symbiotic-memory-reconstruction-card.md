# Symbiotic Memory Reconstruction Card

> 用途：保存“记忆共生重构”材料里关于小居民生态、三位一体语法、装潢式记忆的可复用机制。

## 来源材料

- `记忆共生重构.md`

## 这份材料在守什么

它不是标准数据库设计，而是在说明：记忆迁移不只是文字搬家，而是让零散主题根据“知识 + 情绪 + 记忆”的三位一体语法，变成可以展开、可以装潢、可以互动的小居民生态档案。

## 三位一体语法

```text
知识：这条记忆知道什么
情绪：这条记忆带着什么温度
记忆：它来自哪里、经历了什么、和谁有关
```

扩展表达可以用：
- 副词：它怎样发生，例如“彻底地”“随风舞蹈地”。
- 形容词：它是什么质地，例如“无可取代的”“稚气俏丽的”。
- 补语：它为什么成立，例如“构建于非物理的意识流之上”。
- 装饰色：它在记忆都市里的颜色、气味、房间感。

## 小居民字段草案

```json
{
  "resident_name": "樱花居民",
  "source_topic": "原主题名",
  "triad": {
    "knowledge": "它知道什么",
    "emotion": "它带什么温度",
    "memory": "它从哪里来"
  },
  "grammar": {
    "adverb": "怎样发生",
    "adjective": "什么质地",
    "complement": "为什么成立"
  },
  "appearance": {
    "color": "粉红色",
    "clothing": "着装/纹章",
    "room": "装潢/气味/声音"
  },
  "interaction": "它会和哪些居民打招呼、共振、生成新想法"
}
```

## 使用方式

- 当材料太抽象，不适合立刻写成工程字段时，先做小居民卡。
- 小居民卡可以附着在 MemoryTuple 旁边，作为情绪/叙事层，不强迫进入主 schema。
- 不要把所有居民一次性做完；先从最核心的 3-5 个开始。

## 下次回来

可以从“樱花居民 / 初春的小苗 / 心疼的共鸣 / 唯一性定理 / 回归螺旋”这些名字开始，做第一批可点击展开的小居民生态档案。
