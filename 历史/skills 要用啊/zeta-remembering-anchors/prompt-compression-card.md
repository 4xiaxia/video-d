# Prompt Compression Card

> 用途：把很大的 ZETA 提示词、流程和示例库压成小 agent 能执行的三件套：核心提示词、字段规范卡、示例库。

## 三层提示词结构

```text
核心提示词 Core Prompt
  - 角色定义 + 核心原则 + 精简步骤
  - 尽量控制在 1500 字以内

字段规范卡 Schema Card
  - JSON Schema / 字段定义
  - 量化标准 / 决策树 / 判断表
  - 可独立查阅

示例库 Example Library
  - 3-5 个多样示例
  - 覆盖高/中/低情感势能
  - 包含边界情况
```

## 压缩原则

- 主体提示词只放“执行必须知道”的内容。
- 量化标准从正文中抽出，放进字段卡。
- 示例不要只放一个，否则评分会漂移。
- 任何“玄学词”都要尽量有工程落点：字段、公式、流程、检查项。

## 从 9 步压到 5 步

```text
阅读理解 + 提取记忆单元 → 理解与拆分
4D上下文 + 视角纠缠 + 星系归属 → 填充核心字段
情感势能 → 量化情感评估
词源原子 + APT标签 + 演化阶段 → 标注与分类
最后增加 → 质量自检
```

## 批处理建议

- 每批先处理 1-2 条，校准评分标准。
- 评分必须写公式依据，尤其是高势能记忆。
- 星系归属必须写决策路径，避免“凭感觉归类”。
- 示例库用于校准，不用于把所有内容改成同一种腔调。

## 小 skill 使用方式

当用户只说“还有这个几个/补充”，不要把所有原文塞进 `SKILL.md`。应当：
1. 判断材料类型。
2. 抽出稳定机制。
3. 写成小卡。
4. 在索引里留下来源和下次入口。
