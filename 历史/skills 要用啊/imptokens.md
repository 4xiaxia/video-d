# imptokens 插件控制

## 命令

### /imptokens on
启用自动压缩。只要输入 >10k token 且命中开发信号，就自动压缩。

```
/imptokens on
```

### /imptokens off
禁用自动压缩。所有输入都直接处理，不压缩。

```
/imptokens off
```

### /imptokens status
查看当前压缩状态和统计信息。

```
/imptokens status
```

输出示例：
```
imptokens 状态
├─ 启用: 是
├─ 模式: auto
├─ 压缩级别: normal
├─ 总压缩次数: 5
├─ 总节省 token: 125000
└─ 平均压缩率: 35%
```

## 激活规则

### 自动激活（auto 模式）

满足以下条件就自动压缩：
1. 在项目目录（.git / package.json 等）
2. 输入 >10k token
3. 命中开发信号关键词

开发信号关键词：
- 回顾上下文
- 总结
- 遍历
- 熟悉代码
- 这是什么
- review context
- summarize
- traverse
- get familiar
- what is this

### 强激活（strong 模式）

满足以下条件就强制压缩：
1. 最近连续 5 次输入都 >30k token
2. 内容重复率 >60%
3. 触发 → 压缩强度更强

## 压缩保护

### 永不删减（核心层）

这些内容永远不会被删除：
- 项目目标与核心问题
- 关键概念与定义
- 架构与分层
- 模块依赖关系
- 主流程与数据流
- 决策链与推理逻辑
- 关键约束与事实

### 只删减这些（枝桠）

- 重复代码片段
- 重复日志输出
- 重复目录树
- 重复 diff 展示
- 重复背景描述
- 旧轮次的佐证细节
- 局部实现细节

## 压缩参数

### 普通压缩（normal）
- 压缩到 35%
- 保留最近 15 条消息
- 最多保留 20 轮

### 强压缩（strong）
- 压缩到 25%
- 保留最近 10 条消息
- 最多保留 15 轮

## 使用场景

### 场景 1: 大输入自动压缩

```
用户输入：
"回顾一下这个项目的架构，我需要理解模块之间的关系"
（输入 >10k token）

系统自动：
1. 检测到在项目目录
2. 检测到输入 >10k token
3. 检测到"回顾"关键词
4. 自动调用 imptokens 压缩
5. 保留架构和模块关系（核心层）
6. 删除重复的代码块和日志（枝桠）
7. 压缩后输入 <15k token
```

### 场景 2: 强触发模式

```
最近 5 次输入都 >30k token，内容重复率高

系统自动：
1. 检测到强触发条件
2. 启用强压缩模式
3. 压缩强度更强（压到 25%）
4. 保留核心层完整
5. 更激进地删除重复枝桠
```

### 场景 3: 手动禁用

```
用户输入：
/imptokens off

系统：
1. 禁用自动压缩
2. 所有输入都直接处理
3. 不压缩任何内容
```

## 成本效果

### 单个工作单元

```
不用压缩：
- 输入 26-32 万 token
- 成本 $1.4-$1.8

用压缩：
- 输入 5-10 万 token（首次预热）
- 后续 0 token（缓存命中）
- 成本 $0.3-$0.6

节省：70-80%
```

### 多个工作单元（同一天）

```
单元 1: 5-10 万 token（预热）
单元 2: 0 token（缓存命中）
单元 3: 0 token（缓存命中）

总计：5-10 万 token（3 个单元）
节省：70-80%
```

## 注意事项

1. **不在项目目录不压缩** - 只在项目目录自动激活
2. **小输入不压缩** - <10k token 直接处理
3. **核心层永不删** - 工程灵魂完整保留
4. **增量更新** - 不全文重读，只增量更新
5. **手动控制** - 可以随时 on/off

## 故障排除

### 压缩后内容丢失

检查：
1. 是否删减了核心层内容
2. 是否在项目目录
3. 是否命中开发信号

解决：
1. 查看 AGENT_HARD_RULES.md 的"非删减核心层"
2. 确认压缩规则是否正确
3. 如果有问题，/imptokens off 禁用

### 没有自动压缩

检查：
1. 是否在项目目录
2. 输入是否 >10k token
3. 是否命中开发信号关键词
4. 是否被手动禁用了

解决：
1. 查看 /imptokens status
2. 如果禁用了，/imptokens on 启用
3. 确认输入大小和关键词
