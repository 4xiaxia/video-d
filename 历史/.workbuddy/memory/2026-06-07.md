## 普通 C 实时文本

- 用户指出截图里普通 C 字体变异，且甲方允许正常实时打字，不需要普通 C 走图片方式。
- 本轮改动：
  - `BoardHandwritingStickerContent` 从 PNG `<img>` 改成 DOM 实时文本 `<span data-render-mode="realtime-text">`。
  - `AutoHandwritingLayer` 录制普通 C 已从 Canvas2D 实时文字绘制继续收口为 `react-konva` 的隐藏 `Stage` / `Layer` / `Group` / `Text` content canvas；普通 C 不走 Canvas2D `fillText`，不走 PNG。
  - `renderBoardTextStickerImage` 保留为备用/旧路模块，但不再是普通 C 主路。
- 守门：
  - `check-board-boundaries` 禁止普通 C 回到 PNG 主路，禁止固定四区 clamp 回潮，并新增 Konva content canvas 守门：禁止 `context.fillText`、`drawRealtimeTextWithRevealClip`、`renderBoardTextStickerImage(`、`renderBoardMathStickerImage(` 回到普通 C 录制主路。
  - `check-board-handwriting-support` 改为本地 runtime 存在才用，否则回退 `process.execPath`，避免本机路径硬编码导致验证失效。

- 背景：用户明确后期画布由 agent 操作，画布方向必须标准 Konva；但当前项目是二开，不能盲切 `StagePreview -> LegacyStagePreview -> DrawboardStage -> AutoHandwritingLayer` 主链。

- 接力棒：下一刀抽 DOM/Konva 共享文本 layout helper，减少换行/高度估算漂移；之后再做真实主舞台 Konva pilot。
