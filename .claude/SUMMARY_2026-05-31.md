## 快速理解（3 分钟版）

### 问题1：C 文字没有按标签领地站位

**现象：** 画布上的文字可以随意拖到任何位置，不受四区标签的约束

**根本原因：**
```
四区标签（题目/分析/解答/总结）已经画好了
           ↓
TimelineClip 有 chainKey（知道自己是"template-open"还是"step-1"）
           ↓
但 AutoHandwritingLayer 完全没用 chainKey 来约束位置
           ↓
所以 C 文字可以自由飘动 ❌
```

**修复方案：** 
- 从 chainKey 反推四区范围
- 用户拖放 C 时，自动吸附到对应四区

---

### 问题2：B 播放完毕，C 默认躺平不下台

**现象：** B 的寿命到期后，C 会立即消失（而不是留在舞台上）

**根本原因：**
```
当前逻辑：playheadMs > endMs → C 被过滤掉，消失
用户需求：playheadMs > endMs → C 应该继续显示（演绎完毕的静态态）
```

**修复方案：** 
- 补充 `pinnedEndMs` 字段（"留场结束时间"）
- 现在 C 有两个时间端点：
  - `endMs`：演绎完毕
  - `pinnedEndMs`：真正消失
- 用户可以在时间线拉长 C 的留场时长
