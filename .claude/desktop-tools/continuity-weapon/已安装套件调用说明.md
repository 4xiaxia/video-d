# 已安装套件调用说明

变量约定：

```text
${PROJECT_ROOT} = 当前项目根目录
${CLAUDE_HOME}  = Claude 本机目录
${CODEX_HOME}   = Codex 本机目录
```

## 已装可用

| 套件 | 什么时候用 | 怎么调用 | 验证 |
| --- | --- | --- | --- |
| `local-continuity-standard` | 接手项目、SessionStart、Stop Hook、装项目五件套 | `npm run audit:local-order` 或 `node ${CODEX_HOME}/skills/local-continuity-standard/scripts/install-continuity-standard.mjs` | `node ${CODEX_HOME}/skills/local-continuity-standard/scripts/install-system-skill.mjs --dry-run` |
| `continuity-weapon` | 想从桌面工具目录跑秩序检查/安装引导 | `powershell -File .claude/desktop-tools/continuity-weapon/continuity-doctor.ps1` | `npm run check:suite-buffs` |
| `memory-cache` MCP 包 | MCP 客户端需要 24h 重复读取缓存 | 在 MCP 配置中注册 `node ${CLAUDE_HOME}/cache/ib-mcp-cache-server/build/index.js` | build 文件存在；接入客户端后查 `cache://stats` |
| `imptokens` | 大输入、重复上下文、需要压缩保主线 | `imptokens --help`；Claude 里用 `/imptokens status` | `python ${CLAUDE_HOME}/plugins/imptokens-pruner/bin/controller.py --status` |
| `codesight` | 快速看项目结构、wiki、爆炸半径，不想全仓乱读 | `codesight --wiki --max-tokens 12000`；`codesight --blast <file>`；`codesight --mcp` | 已生成 `.codesight/wiki/index.md` |
| `graphify` | 需要项目关系图、查询图谱、后续 GraphRAG | `graphify detect . --scope auto`；完整语义图需 `graphify extract . --backend <provider>` 或 skill 流程 | CLI 已可用；当前只完成 detect/AST cache，完整 `graph.json` 未完成 |
| `cc-wf-studio` | 把项目流程变成 workflow，可验证、可导出、可 MCP 编辑 | `ccwf validate .vscode/workflows/<file>.json`；`ccwf render <file>`；`ccwf-mcp --file <file>` | `.vscode/workflows/continuity-gate-smoke.workflow.json` 已验证 |
| 桌面眼睛鼠标 | 需要看屏幕、截图、局部放大、点击、T.Claw | `.claude/desktop-tools/eye-full.ps1`、`eye-region.ps1`、`hand-click.ps1`、`tclaw-start.ps1` | 文件存在；运行产物不入工程真相 |

## 规则

- 渐进式安装：缺哪个命令，只装哪个命令。
- 不捆死目录：配置用变量或相对路径。
- 不捆死环境：候选不进 required，smoke 通过才升级。
- 不把“已登记”写成“已完成”。
