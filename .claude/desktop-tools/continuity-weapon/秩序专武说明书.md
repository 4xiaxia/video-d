# 秩序专武 · Continuity Weapon

> 开工先校准秩序，再进入项目。规则包不捆死项目，也不捆死本机环境。

## 这是什么

一套便携 PowerShell 入口，用来引导安装和审计 `local-continuity-standard` 规则包。

它只做三件事：

- 预览/安装系统级 Codex skill。
- 给任意项目投放连续性五件套和检查脚本。
- 开工前审计项目是否具备秩序入口。

## 规则

- 默认只预览，不偷偷安装。
- 不覆盖已有记录，除非显式传覆盖参数。
- 不写死项目路径、本机用户名、Claude/Codex 目录。
- 具体工具栈写进项目的 `scripts/continuity-stack.config.json` 或用 `CONTINUITY_STACK_CONFIG` 指定。

## 会用的套件

看 `会用的套件清单.md`。核心分层是：

```text
连续性层 -> 压缩层 -> 锚点层 -> 图谱层 -> 工作流编排层 -> 缓存层 -> 本地模型/分流层 -> 桌面操控层
```

这些都是可配置适配层，不写死进规则包。

检查 buff 清单：

```powershell
.\continuity-check-buffs.ps1
```

## 快速使用

### 1. 审计当前项目

```powershell
.\continuity-audit.ps1 -ProjectPath D:\your-project -SkillPath D:\path\to\local-continuity-standard
```

如果项目已经安装了 `scripts/audit-local-order.mjs`，可以不传 `-SkillPath`。

### 2. 给项目安装五件套

```powershell
.\continuity-install-project.ps1 -ProjectPath D:\your-project -SkillPath D:\path\to\local-continuity-standard
```

安装器只创建缺失文件，不覆盖已有项目记录。

### 3. 预览系统级 skill 安装

```powershell
.\continuity-install-system-skill.ps1 -SkillPath D:\path\to\local-continuity-standard
```

### 4. 真正安装系统级 skill

```powershell
.\continuity-install-system-skill.ps1 -SkillPath D:\path\to\local-continuity-standard -Yes
```

### 5. 指定安装目标

```powershell
.\continuity-install-system-skill.ps1 -SkillPath D:\path\to\local-continuity-standard -Target D:\portable-codex\skills -Yes
```

## 专武口令

没有秩序，不进项目。
