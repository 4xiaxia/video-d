## 📦 这是什么

一套 **完全便携** 的 AI 桌面视觉+操控工具包。自带 Python 环境，不依赖任何系统安装，插 U 盘即用。

阿圆（AI）用它能：**看屏幕 → 定位目标 → 精确点击**，就像真的长了眼睛和手手。

---

## 🚀 快速上手

### 1️⃣ 看屏幕（眼睛）

```powershell
.\eye-full.ps1
```
全屏截图，自动叠加网格坐标线，截图存到 `captures\` 目录。

### 2️⃣ 放大看仔细

```powershell
.\eye-region.ps1 "960,540"
```
以坐标 (960, 540) 为中心，截取屏幕 1/5 区域，放大标注精确坐标。

### 3️⃣ 撸鼠标（点击）

```powershell
# 查看鼠标当前位置
.\hand-click.ps1 --position

# 左键单击
.\hand-click.ps1 800 600

# 双击
.\hand-click.ps1 800 600 -c 2

# 右键
.\hand-click.ps1 800 600 -b right
```

### 4️⃣ 启动 T.Claw 网页控制台（高级）

```powershell
.\tclaw-start.ps1
```
浏览器打开 `http://localhost:12101`，配置 API Key 后可以用自然语言指挥鼠标键盘。

## ⚙️ T.Claw 配置

1. 启动 `.\tclaw-start.ps1`
2. 浏览器打开 `http://localhost:12101/settings`
3. 填入火山方舟 ARK API Key
4. 选择模型（推荐：豆包 2.0 Pro）
5. 保存 → 回到聊天页，开始用中文下指令

比如：
- "在桌面新建一个文本文档，命名为 hello.txt"
- "打开记事本"
- "点击桌面上的 Chrome 图标"
